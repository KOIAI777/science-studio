# Science Studio UI 定义 v0.5

更新日期：2026-07-30

## 1. 体验原则

### 海外与英语优先

产品界面、模板默认文案和导出内容以英语为真源，简体中文作为可选本地化。公式、变量、SI 单位和模板 ID 不翻译；项目显式保存语言，切换界面语言不能静默修改已有讲解内容。

### 课堂使用优先

产品主页先让海外教师理解产品用途并进入免费实验，实验目录作为主页核心板块服务于按课程寻找内容；实验页以模拟画布为视觉中心。所有面板服务于参数调整、科学理解和课堂展示，不使用装饰性卡片或聊天窗口挤占画布。

### 模板驱动

首版不向用户暴露物理引擎和自由场景工具。界面只显示当前模板允许修改的参数、观察项和讲解步骤。

### 精确且可解释

关键参数同时提供数值输入和精确滑杆，始终显示单位。科学警告必须说明位置、原因和处理方式。

### 轻量创作

内容编排采用有限的讲解步骤，不复制完整视频编辑器。用户调整的是“解释顺序”，不是任意媒体轨道。

### 克制的动效

动效只用于建立状态连续性、显示操作结果和降低界面跳变。实验数值、公式和测量结果不做娱乐化动画。

### 目录、工作台与课堂展示分层

主页使用深色课堂工作台首屏与浅色教材式内容区，并以紧凑板块连接独立实验目录；实验目录使用浅色教材式界面，工作台使用深色、安静的工具界面，课堂展示只保留纸白实验画布和必要控制。三个界面的控件密度不能混用。

语言切换位于工作台工具栏，不进入导出画面。英文是首次打开时的默认语言，所有英文长文本必须按实际容器验证，不能依赖中文字符密度推断布局。

## 2. 信息架构

```text
Science Studio
├── 首页
│   ├── 产品定位与免费实验入口
│   ├── 实验目录入口
│   ├── 教师使用流程
│   ├── 实验包规划
│   └── FAQ
├── 实验工作台
│   ├── 实验
│   ├── 讲解
│   └── 展示
└── 实验包（内容达到销售条件后）
```

独立路由 `/experiments` 承载分级筛选、主题筛选、搜索、结果统计和分页。

验证版使用标准产品主页，开放斜面、能量轨道、力和运动与 Ohm's Law Lab 四个免费实验。Ohm's Law Lab 固定为单电源、单电阻、单开关的理想直流回路；串联、并联、混联、自由布线、多电阻和探针表不进入免费层。未完成模板不进入实验目录，只在路线与实验包文案中说明；当前不创建账户、账单、学生课堂或数据分析页面。

## 3. 页面定义

### 3.1 首页 `/`

目标：让首次访问的海外教师理解产品价值，看到真实课堂效果，并在一分钟内进入免费实验或按学段寻找实验。

- 顶部固定导航包含品牌、`Experiments`、`How it works`、`Pricing`、`FAQ`、语言切换和 `Try a free experiment`。
- 首屏标题明确产品类别，说明教师课堂展示用途，并使用真实斜面受力图和同步测量结果作为主视觉。
- 首屏之后依次展示产品可信点、实验目录入口、三步教师流程、课堂功能、实验包规划、FAQ 和最终体验入口。
- 顶部 `Experiment library` 和首页目录入口均跳转 `/experiments`。
- 实验卡使用从已发布模板实际运行画布截取的封面，显示教学时长、核心概念和内容状态；不为未完成实验手绘占位缩略图。
- `Free`、`Included in level pack`、`Planned` 使用文字和图标共同表达。
- 只有完成的实验可以点击；未完成实验不得显示购买操作。
- 搜索匹配标题、说明和核心概念。
- 独立实验目录每页稳定显示 6 个结果，分页链接保留全部筛选参数，并提供可访问的 `aria-current` 页码状态。
- 价格卡明确区分 `Available now`、`Planned early access` 和 `Future release`；只有当前可用的免费计划包含操作按钮。
- 页面必须包含唯一 `h1`、语义化章节、规范 URL、Open Graph、Twitter Card、JSON-LD、`robots.txt` 与 `sitemap.xml`。

### 3.2 模板库 `/templates`

目标：在一分钟内判断模板是否适合当前知识点。

- 可用模板以真实运行缩略图展示；只有一个模板时不显示筛选和搜索。
- 点击模板后打开右侧详情抽屉，不跳转页面。
- 抽屉包含可交互预览、学习目标、可调参数、可视化项、默认假设和示例输出。
- 主操作是“使用此模板”，次操作是切换 `9:16/16:9/1:1`。
- 模板来源、求解器版本和科学说明可展开查看，但不与主操作争夺视觉层级。

### 3.3 项目编辑器 `/projects/:id`

编辑器采用稳定的三区加底栏结构：

```text
┌──────────────────────────────────────────────────────────────┐
│ 返回 / 项目名 / 保存状态 / 实验·讲解·导出 / 科学检查        │ 48
├───────────────────────────────────────────┬──────────────────┤
│                                           │ 参数或步骤面板   │
│                模拟画布                   │ 336              │
│                                           │                  │
├───────────────────────────────────────────┴──────────────────┤
│ 播放控制 + 时间 / 图表或讲解步骤                              │ 64-224
└──────────────────────────────────────────────────────────────┘
```

稳定尺寸：

- 顶栏高度 `48px`。
- 右侧面板默认宽度 `336px`，可在 `300-400px` 调整。
- 底部播放条最小高度 `64px`；展开后最大 `224px`。
- 画布最小可用尺寸 `680 x 420px`。
- 模式切换、加载提示和动态数值不能改变这些区域尺寸。

#### 顶栏

- 左侧为返回、项目名和保存状态。
- 中间使用 `实验 | 讲解 | 导出` 分段控制。
- 右侧显示撤销、重做和科学检查。
- 导出模式中的“开始导出”是唯一高强调操作。
- 保存状态只在“保存中”“离线”“冲突”“失败”时持续可见。

#### 实验模式

画布：

- 画幅外使用深色点阵工作区；真实输出画幅使用纸白背景，并显示安全区和低对比坐标网格。
- 已发布模板只显示自身支持的画幅比例。`Forces & Motion` 使用 `9:16 | 16:9` 分段控制；两个画幅分别重排内容，不使用非等比拉伸。
- 画布工具栏提供 `50%-250%` 缩放（步长 `25%`）、移动、`Fit` 和浏览器全屏。缩放超过 `100%` 后才启用移动，移动同时支持指针拖动和方向键。
- `Fit` 恢复 `100%` 并居中；切换画幅同样恢复 `Fit`，但保留实验参数、当前模拟时间、实验/讲解模式和讲解内容。全屏状态下保留画布工具栏和完整播放时间轴，隐藏顶部导航与参数面板。
- 轨迹、力、速度和加速度使用固定语义色。
- 标签、箭头和选择目标随输出画幅保持同一坐标关系并同步缩放；画布工具栏和参数面板不参与缩放。
- 画幅、缩放、移动、`Fit` 和全屏均属于视口状态，不得改变求解器状态或 SI 测量值。
- P0 没有添加物体工具栏；画布对象可以点击，以定位相关参数和检查结果。

右侧面板：

```text
实验参数
可视化
画面样式
科学说明
```

- 参数行采用“名称 / 输入值 / 单位”。
- 推荐范围内使用精确滑杆；输入框允许键盘输入。
- 超出推荐范围显示琥珀提示，非法值在原位置显示错误。
- 向量方向使用角度或方向控件，不要求用户计算分量。
- 开关只控制二元设置，选项集合使用分段控制或菜单。

底部：

- 固定显示重置、前后单步、播放/暂停、速度和时间。
- 可展开查看模板提供的最多两张图表。
- 图表游标和画布时间同步。

#### 讲解模式

- 画布保持与实验模式相同的渲染结果，并显示当前讲解步骤的标注。
- 右侧面板编辑当前步骤的标题、持续时间、播放区间和显示项。
- 底部使用横向步骤列表，而不是自由轨道时间线。
- 每个步骤拥有固定宽度和高度，包含序号、名称、持续时间和缩略图。
- 支持排序、复制、删除和恢复默认步骤。
- 拖动步骤时不改变画布或底栏高度。

#### 导出模式

- 中间显示最终画面和完整步骤预览。
- 右侧依次显示科学检查、构图检查、格式、分辨率和预计额度。
- 阻断问题必须处理后才能提交；建议项允许带说明继续。
- 提交后停留在项目中显示任务状态，不使用全屏等待页面。

### 3.4 订阅与账单 `/settings/billing`

- 显示当前方案、续费状态、周期结束日期和渲染额度。
- “升级”调用 Creem Checkout，“管理订阅”进入客户门户。
- 付款失败和权益失效使用页面级状态，不隐藏在普通通知中。
- 取消时明确最后可用日期，不使用诱导性多步确认。

## 4. 状态规则

### 模拟

- `Ready`：可编辑和播放。
- `Running`：参数变化会先暂停，再重新计算。
- `Paused`：可以修改参数并从当前时刻继续或重置。
- `Invalid`：非法参数阻止播放，并定位输入项。
- `Error`：保留项目，允许恢复到最近可运行版本。

### 保存

- 本地状态立即更新，空闲 `800ms` 后保存。
- 离线时保留待同步副本，并显示“离线编辑”。
- 服务端以 `revision` 防止静默覆盖另一设备的新版本。

### 科学检查

- 红色：阻止运行或导出。
- 琥珀色：建议修正。
- 蓝灰色：已知假设。
- 绿色：仅用于一次明确的“检查通过”结果。
- 颜色不是唯一线索，必须同时使用图标、标题和说明。

## 5. ReactBits 使用规范

[ReactBits](https://github.com/DavidHDev/react-bits) 作为局部动效源码库，不作为基础组件库。基础按钮、菜单、输入框、对话框和可访问性状态仍由 Radix/shadcn 模式承担。

### 可以使用

| ReactBits 组件 | 使用位置 | 限制 |
|---|---|---|
| `AnimatedContent` | 模板详情抽屉、检查结果区切换 | `120-180ms`，不移动主画布 |
| `FadeContent` | 缩略图、图表和导出结果加载完成 | 只淡入一次，禁止循环 |
| `AnimatedList` | 最近导出任务、科学检查结果 | 新增或移除时使用，不对稳定列表持续排序 |
| `Stepper` | 首次使用引导或首次导出流程 | 最多 4 步，允许跳过，不替代编辑器模式导航 |

### 不用于核心工作台

- `ElasticSlider`：物理参数需要精确、可预测的控制反馈。
- `Dock`、`BubbleMenu`、`GooeyNav`：会改变控件尺寸或位置，不适合高频工具栏。
- `CountUp`：测量值必须即时准确，不做滚动数字动画。
- `SpotlightCard`、`TiltedCard`、`MagicBento`：不把工作区做成展示型卡片墙。
- `BlurText`、`GlitchText`、`GradientText`：不用于标题、公式或科学结论。
- 背景、光束、粒子和光标特效：不进入编辑器和模拟输出。

### 工程与许可证边界

- 只拷入实际采用的 TypeScript + Tailwind 版本，放入独立目录并保留来源说明。
- 不安装或复制整套组件库，不二次出售、打包或分发组件集合。
- 截至 2026-07-29，ReactBits 仓库声明为 `MIT + Commons Clause`，允许作为应用的一部分商用，但禁止销售或重新分发组件本身；正式发布前重新核对许可证。
- 所有动效支持 `prefers-reduced-motion`，关闭后仍保留完整功能和状态反馈。
- 动效不能改变固定工具栏、画布、参数行和测量值的布局尺寸。

## 6. 视觉系统

视觉基线已经通过弹簧振子技术样片验证：采用炭黑工具工作台、纸白实验输出和少量物理语义色。弹簧振子样片本身不属于产品范围，只保留其视觉结论。界面不使用大面积渐变、玻璃效果或单一蓝紫色主题。

| Token | 建议值 | 用途 |
|---|---|---|
| `surface-app` | `#171816` | 工作区背景 |
| `surface-panel` | `#20211F` | 参数面板与工具栏 |
| `surface-raised` | `#292A27` | 输入和局部强调面 |
| `surface-canvas` | `#F6F7F2` | 实验输出画布 |
| `text-on-dark` | `#ECEEE8` | 工作台主文字 |
| `text-muted` | `#9A9D95` | 工作台辅助文字 |
| `text-on-canvas` | `#181917` | 输出画布主文字 |
| `border-default` | `#3B3D38` | 工作台分隔与边框 |
| `action-primary` | `#F6F7F2` | 导出等唯一主操作 |
| `accent-control` | `#EF6548` | 选中、播放头和参数滑杆 |
| `accent-measure` | `#2659A8` | 位移、公式和图表 |
| `accent-force` | `#E85D42` | 力矢量 |
| `accent-velocity` | `#12766D` | 速度与运动状态 |
| `focus-ring` | `#8EB3FF` | 键盘焦点 |
| `warning` | `#D18A32` | 建议与近似 |
| `danger` | `#E05A4F` | 阻断问题 |

- 深色工作台不得改变导出画布的颜色；导出只包含 `surface-canvas` 内的内容。
- 主操作使用纸白底和炭黑文字，珊瑚红只承担控制状态和物理语义，不铺满界面。
- 输出画布中的数据卡片保持无装饰或细边框，不使用工作台式悬浮卡片。

字体和尺寸：

- 英文优先使用 `Inter` 或系统无衬线字体，中文回退到 `PingFang SC`；数学公式使用 KaTeX 字体。
- 数值使用 `tabular-nums`。
- 页面标题 `20/28px`，面板标题 `13/20px`，正文 `14/20px`，辅助文字 `12/18px`。
- 不随视口缩放字号，字距为 `0`。
- 输入和按钮高 `32px`，主操作可为 `36px`。
- 圆角为 `6px`，菜单和对话框最大 `8px`。
- 图标统一使用 Lucide，普通 `16px`、工具按钮 `18px`。

## 7. 响应式与无障碍

- `>= 1280px`：完整编辑体验。
- `1024-1279px`：右面板缩至 `300px`，底部图表默认折叠。
- `< 1024px`：画布、播放和基础参数编辑可用；参数面板位于画布下方，播放条不得悬浮遮挡参数。讲解编排和导出设置可以只读或延后到桌面完成。
- 图标按钮均有可访问名称和 Tooltip。
- 拖动和滑杆均提供键盘及数值输入替代方案。
- 图表提供图例、当前值文本和数据表视图。
- 关键文本和控件满足 WCAG AA 对比度。
- 减少动态效果模式下禁用所有非必要转场。

## 8. 下一轮视觉验证范围

1. 斜面模板的竖屏实验编辑状态。
2. 同一项目的讲解步骤状态。
3. 本地导出前的科学检查和构图检查状态。

不再单独制作模板库视觉稿，直到斜面闭环通过用户验证。下一轮必须验证参数是否容易理解、讲解步骤是否足够、科学状态是否可信，以及 ReactBits 动效是否保持克制。
