# Science Studio UI 定义 v0.1

更新日期：2026-07-29

## 1. 体验原则

### 场景优先

实验画布始终是编辑器的视觉中心。工具栏和面板服务于场景，不用欢迎卡片、装饰插画或聊天窗口抢占主要空间。

### 参数必须可见

用户选择物体后，影响实验结果的关键参数应立即出现。优先使用带单位的数值输入、滑杆和开关，不把高频参数藏进多层菜单。

### 科学状态可解释

警告必须说明“哪里有问题、为什么、如何处理”。模拟值、理论值和误差需要清楚区分。

### 创作与模拟分层

“实验”负责物体、参数和测量；“讲解”负责镜头、标注和时间。两者共享场景，但不能把视频编辑控件长期堆在实验编辑界面中。

### 专业但不工程化

界面应像现代创作工具，保持安静、精确和高信息密度；避免仿黑板、实验室仪器皮肤和过多拟物装饰。

## 2. 信息架构

```text
Science Studio
├── 首页
│   ├── 最近项目
│   ├── 收藏模板
│   └── 导出任务
├── 模板库
│   ├── 力与运动
│   ├── 振动
│   └── 碰撞与守恒
├── 项目编辑器
│   ├── 实验
│   ├── 讲解
│   └── 发布
├── 分享预览
├── 订阅与账单
└── 账户设置
```

全局导航仅包含：首页、模板、项目和账户。帮助、反馈和快捷键放在账户菜单或编辑器帮助菜单中。

## 3. 页面定义

### 3.1 首页 `/home`

目标：让回访用户在 10 秒内继续最近工作，或从合适模板开始。

布局：

- 左侧固定导航，宽度 `224px`。
- 顶部一行显示页面标题、搜索和“新建项目”。
- 主区首先显示最近项目的紧凑网格，卡片比例固定为 `16:10`。
- 下方显示收藏模板和最近导出任务，使用列表而不是嵌套卡片。
- 项目卡显示真实场景缩略图、名称、更新时间、画面比例和科学检查状态。
- 悬停后显示打开、复制和更多操作；删除只存在于更多菜单，并要求确认。

空状态直接展示 3 个推荐模板和“浏览全部模板”，不使用营销文案。

### 3.2 模板库 `/templates`

目标：根据要解释的知识点找到可信起点。

布局：

- 顶部搜索支持知识点、公式和物理量。
- 左侧筛选：主题、年级/难度、用途、画面比例。
- 主区模板缩略图显示真实运行状态，不使用抽象封面。
- 模板详情使用右侧抽屉，不跳转新页面。

详情必须包含：

- 可交互预览
- 学习目标
- 可调整变量
- 默认假设与适用范围
- 可观察测量项
- 模板来源和版本
- “使用此模板”主按钮

### 3.3 项目编辑器 `/projects/:id`

这是产品的核心页面，采用稳定的四区布局：

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：返回 / 项目名 / 保存状态 / 模式 / 检查 / 导出         │ 48
├──────┬───────────────────────────────────────┬───────────────┤
│ 工具 │                                       │ 属性面板      │
│  48  │              实验画布                 │ 320           │
│      │                                       │               │
│      │                                       │               │
├──────┴───────────────────────────────────────┴───────────────┤
│ 底部面板：播放控制 / 时间 / 测量或讲解时间线                 │ 180-280
└──────────────────────────────────────────────────────────────┘
```

稳定尺寸：

- 顶栏高度 `48px`。
- 左工具栏宽度 `48px`，只使用图标并提供 Tooltip。
- 右属性面板默认宽度 `320px`，允许在 `280-420px` 调整。
- 底部面板默认高度 `220px`，允许折叠和调整。
- 画布最小可用尺寸 `640 x 420px`。

#### 顶栏

- 左侧：返回项目、可编辑项目名。
- 中间：`实验 | 讲解 | 发布` 分段控制。
- 右侧：保存状态、撤销、重做、科学检查、导出。
- 自动保存状态只显示“保存中”“已保存”“保存失败”，不持续显示无意义成功提示。
- “导出”是唯一高强调按钮。

#### 左工具栏

- 选择
- 基础物体
- 约束
- 测量器
- 标注
- 公式
- 视图工具

点击带子类型的工具后打开靠近工具栏的弹出面板。拖入画布后保持选择状态，连续创建需要用户主动锁定工具。

#### 画布

- 默认浅色中性背景和低对比网格，支持隐藏网格。
- 画布内显示输出画幅边界和安全区，画幅外区域降低明度。
- 选择物体显示边框、旋转柄和方向明确的操作柄。
- 物理矢量使用固定语义色，不能随主题任意改变。
- 缩放不改变控制柄和标签的屏幕尺寸。
- 右键菜单提供复制、删除、锁定、置顶/置底和聚焦。
- 空格拖动画布，滚轮缩放；快捷键仅在帮助面板展示，不在界面上写说明文字。

#### 右属性面板

根据选中对象切换内容，不使用多层卡片：

```text
对象名称与显隐
位置与尺寸
物理属性
初始状态
外观
数据与标注
```

规则：

- 参数标签、输入值和单位在同一行。
- 常用数值同时提供输入框和滑杆；滑杆范围来自模板安全范围。
- 超出推荐范围不立即阻止输入，但显示原因和可能影响。
- 向量使用方向控件加数值输入，不要求用户手算 x/y 分量。
- 二元设置使用开关或复选框；枚举设置使用下拉菜单或分段控制。
- 修改参数时画布即时预览，模拟运行中修改高风险参数则自动暂停。

#### 底部面板：实验模式

- 第一行固定显示重置、后退一步、播放/暂停、前进一步、播放速度和时间。
- 第二层可在“测量”“图表”“事件”三个标签间切换。
- 图表支持缩放、游标和多曲线显隐。
- 点击时间或图表位置会同步画布状态。

#### 底部面板：讲解模式

- 使用水平时间线，轨道固定为镜头、标注、公式和音频。
- MVP 不提供任意新增轨道，防止变成完整视频编辑器。
- 时间线片段有稳定高度，选中和拖动不能引起布局跳动。
- 画布继续显示真实模拟，可在暂停点编辑标注。

#### 发布模式

发布模式不是单独的浮层，而是编辑器内的检查页：

- 左侧/中心显示最终画面预览。
- 右侧显示科学检查、构图检查和导出设置。
- 必须先处理阻断问题；建议项可以带说明继续导出。
- 显示预计时长、输出尺寸和预计额度消耗。

### 3.4 分享预览 `/s/:shareId`

- 首屏直接显示实验，不显示产品营销页。
- 作者开放的参数放在右侧紧凑面板。
- 访问者可以播放、暂停、重置和调整开放参数，不能修改结构。
- 显示实验假设、来源和作者信息。
- 移动端将参数面板改为底部抽屉，画布保持完整比例。

### 3.5 订阅与账单 `/settings/billing`

- 显示当前方案、状态、下次续费日期和本周期渲染额度。
- “升级方案”调用 Creem Checkout。
- “管理订阅”进入 Creem Customer Portal 或等价自助流程。
- 付款失败状态提供重试入口，但不伪装成普通通知。
- 取消订阅使用确认对话框，明确权益结束日期。

## 4. 核心交互状态

### 模拟状态

- `Ready`：可以编辑和运行。
- `Running`：禁止修改会破坏连续性的结构属性；视觉属性仍可修改。
- `Paused`：允许修改参数，并从当前时间继续或重置。
- `Unstable`：自动暂停，说明数值不稳定的参数和建议范围。
- `Error`：保留用户项目，提供恢复到上一个可运行状态。

### 保存状态

- 本地编辑立即更新 UI。
- 空闲 `800ms` 后增量保存。
- 离线时保留本地待同步状态，并明确显示“离线编辑”。
- 同一项目在另一设备出现新版本时，不静默覆盖；提示选择保留当前副本或载入云端版本。

### 科学检查状态

- 红色：阻断导出，例如非法质量、冲突约束或模拟发散。
- 琥珀色：建议修正，例如误差偏高或标注与单位不一致。
- 蓝灰色：已知假设，例如忽略空气阻力。
- 绿色只用于明确的“检查通过”，不把所有正常控件染绿。

## 5. 视觉系统

### 色彩

采用中性工作台基底和少量功能色，不使用单一蓝紫色主题。

| Token | 建议值 | 用途 |
|---|---|---|
| `surface-app` | `#F3F4F6` | 应用背景 |
| `surface-panel` | `#FFFFFF` | 面板与工具栏 |
| `surface-canvas` | `#FAFAF8` | 实验画布 |
| `text-primary` | `#18181B` | 主文字 |
| `text-secondary` | `#62656B` | 次级文字 |
| `border-default` | `#D8DADD` | 分隔与边框 |
| `action-primary` | `#146C94` | 主操作和选中状态 |
| `accent-measure` | `#6D5BD0` | 测量与图表 |
| `accent-force` | `#D94841` | 力矢量 |
| `accent-velocity` | `#16856B` | 速度矢量 |
| `warning` | `#B86B00` | 建议与近似 |
| `danger` | `#C7352B` | 阻断问题 |

颜色不能作为唯一状态线索，必须配合图标和文字。

### 字体

- 中文界面：系统无衬线字体，优先 `PingFang SC`。
- 数值与时间：使用支持等宽数字的系统字体特性 `tabular-nums`。
- 公式：KaTeX/LaTeX 数学字体。
- 页面标题 `20px/28px`，面板标题 `13px/20px`，正文 `14px/20px`，辅助信息 `12px/18px`。
- 不随视口宽度缩放字号，字距为 `0`。

### 间距与形状

- 基础间距单位 `4px`，主要使用 `8/12/16/24px`。
- 面板之间用边框分隔，不做漂浮卡片。
- 按钮和输入框高度 `32px`，主操作可为 `36px`。
- 圆角：输入和按钮 `6px`，菜单和对话框 `8px`，不使用胶囊式文字按钮。
- 图标尺寸 `16px`，工具栏图标 `18px`，统一使用 Lucide。

## 6. 响应式规则

### 桌面 `>= 1280px`

完整编辑体验，四区同时可见。

### 小型桌面 `1024-1279px`

- 右属性面板缩至 `280px`。
- 底部面板默认折叠到播放控制条。
- 左侧仍保持图标工具栏。

### 平板和手机 `< 1024px`

- 首页、模板库、分享预览和账单页必须可用。
- 项目编辑器仅提供预览、播放、开放参数调整和轻量标注。
- 不承诺在手机上完成场景结构编辑和时间线剪辑。
- 不把桌面面板简单横向压缩；属性改为全高抽屉或底部面板。

## 7. 无障碍与输入

- 所有图标按钮提供可访问名称和 Tooltip。
- 键盘可以完成选择、删除、撤销、重做、播放和参数输入。
- 焦点环清晰，不依赖浏览器默认之外的低对比阴影。
- 文本和关键控件满足 WCAG AA 对比度。
- 图表提供当前值文本、曲线图例和可切换的数据表视图。
- 拖拽操作提供数值输入替代方式。
- 用户开启减少动态效果后，关闭非必要转场和弹性动画。

## 8. 文案规则

- 使用用户熟悉的科学概念，不暴露引擎术语，如 timestep、solver iteration。
- 参数采用“名称 + 数值 + 单位”，例如“质量 2.0 kg”。
- 错误先说结果，再说原因和处理方法。
- 避免“神奇生成”“一键创作”等不可验证描述。
- 删除、覆盖和扣除额度前明确说明后果。

示例：

- 好：`弹簧刚度过高，当前预览可能不稳定。将刚度降至 800 N/m 以下，或提高计算精度。`
- 差：`模拟错误，请重试。`

## 9. 首轮视觉稿范围

首轮只设计以下 3 个关键状态，不先铺满所有页面：

1. 模板库及模板详情抽屉
2. 斜面受力项目的实验编辑状态
3. 同一项目的讲解时间线与竖屏构图状态

这三张稿需要验证：模板是否可信、参数编辑是否清楚、实验和内容编排能否共用同一工作台。

## 10. UI 验收清单

- 画布在常见桌面尺寸中始终是最大视觉区域。
- 任何动态内容、长项目名和最大数值都不会推动布局跳动。
- 属性面板中的所有参数都有单位、范围或解释入口。
- 播放、暂停、重置、撤销和导出在所有编辑模式中位置稳定。
- 画面比例改变后，安全区和越界提示即时更新。
- 科学警告能定位到对应对象或参数。
- 键盘、触控板和鼠标均可完成核心桌面流程。
- 空、加载、离线、冲突、渲染失败和订阅失效状态均有定义。
