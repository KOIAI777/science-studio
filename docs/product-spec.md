# Science Studio 功能定义 v0.4

更新日期：2026-07-30

## 1. 产品定义

Science Studio 是面向海外科普短视频创作者的二维力学内容制作工具，首发服务英语市场。用户从经过验证的实验模板出发，修改参数、选择需要展示的物理量、编排讲解步骤，并导出可发布的视频。

它不是专业工程仿真软件，不是通用视频编辑器，也不是“输入提示词后生成不可编辑视频”的 AI 工具。

### 一句话价值

不用写代码，在 10 分钟内把一个力学知识点做成可验证、可修改、可发布的科学动画。

### 首版核心壁垒

1. **结构化模板**：视频由参数、求解器、测量项、镜头步骤和科学规则组成，不是一段生成后无法修改的素材。
2. **确定性计算**：相同模板版本和参数必须产生相同结果，并能与理论结果比较。
3. **科学检查**：明确单位、参数范围、适用假设和数值误差，AI 不作为正确性的判定来源。
4. **内容工作流**：实验参数、科学标注、讲解步骤和多画幅导出在同一项目中完成。

## 2. 首发用户

### P0：英语市场的高频科普创作者

- 在 TikTok、YouTube Shorts 或 Instagram Reels 发布英语物理、数学、工程科普。
- 每周至少制作一条内容。
- 懂要讲的概念，但不熟悉 Manim、Blender 或物理引擎代码。
- 愿意为节省制作时间、稳定导出和提高可信度付费。

### P1：科学教师

教师可以使用首版导出课程视频，但课堂实时演示、学生副本和作业流程不进入 P0。先验证创作者的持续导出和付费，再决定是否做独立教师入口。

### 暂不服务

- 需要有限元、流体、分子或工业认证结果的工程团队。
- 只想输入一句话立即获得完整成片的泛内容用户。
- 需要复杂三维建模、角色动画或完整非线性剪辑的创作者。

## 3. 首版用户任务

> 当我要解释一个力学知识点时，我希望选择一个可信的实验起点，修改题目中的参数，看见结果并编排关键讲解步骤，然后直接导出适合平台比例的视频。

成功标准：英语使用者无需接触代码，可以在 10 分钟内从模板导出一段 20-30 秒的英文竖屏科学动画。

## 4. P0 产品范围

P0 是用于验证内容生产闭环的本地版本，不是商业 Beta。它只回答“目标用户能否更快做出可信成片、是否愿意再次使用和付费”，不包含账户、云项目、在线支付或模板市场。

### 4.1 一个验证模板

P0 只提供 **斜面受力与摩擦**：角度、质量、静/动摩擦系数和重力；展示受力分解、临界滑动条件、加速度、速度和位移。

该模板必须提供：

- 参数 Schema、默认值、单位、合法范围和推荐范围
- 确定性求解器及模板版本
- 可显示的物体、轨迹、矢量、测量值和公式
- 默认讲解步骤和竖屏构图预设
- 校验规则、理论结果、适用假设和已知误差
- 至少三组自动化基准样例

抛体运动和一维碰撞是验证后的候选模板，不进入 P0 排期。一个模板可以验证编辑与导出工作流，但不能证明模板市场需求。

### 4.2 项目

- P0 直接打开斜面项目，不提供空白项目或模板库。
- 项目先保存为本地文档，支持刷新恢复和导入/导出 JSON。
- 项目保存模板版本、内容语言、参数、视觉设置、讲解步骤和导出预设。
- P0 的产品界面和导出内容默认使用英语，允许切换简体中文；公式、变量和 SI 单位不随语言变化。
- 模板升级不静默修改已有项目；用户明确选择后才迁移副本。
- 云端自动保存、重命名、复制、删除和最近项目列表进入付费 Beta。

### 4.3 参数编辑

- 右侧面板显示当前模板开放的参数。
- 每个数值必须显示单位；高频参数同时提供数值输入和精确滑杆。
- 参数超出推荐范围时说明影响，超出合法范围时阻止运行。
- 修改参数后即时重算场景、图表和科学检查。
- P0 不允许自由添加物体、关节或约束。

### 4.4 科学可视化

- 播放、暂停、单步、重置和 `0.25x/0.5x/1x/2x` 速度预览。
- 按模板显示轨迹、速度、加速度、受力和关键位置。
- 按模板显示不超过两张核心图表。
- 公式使用 LaTeX 渲染，变量值与项目参数同步。
- 图表游标、画布状态和时间显示保持同步。

### 4.5 科学检查

- 检查单位、非法参数、无意义初始条件和求解器异常。
- 根据模板比较理论结果和模拟结果。
- 显示当前假设，例如忽略空气阻力、点质量或一维碰撞。
- 问题分为“阻止导出”“建议修正”“已知假设”三个等级。
- 每条问题说明对象、原因和建议操作。
- AI 可以解释检查结果，但不能覆盖规则结果。

### 4.6 讲解步骤

P0 使用结构化步骤，不做自由时间线。默认步骤示例：

1. 展示初始条件，持续 2 秒。
2. 播放运动并显示轨迹，持续 5 秒。
3. 在关键时刻暂停，显示受力或速度矢量。
4. 显示公式与代入值。
5. 显示结论。

用户可以：

- 调整步骤顺序、持续时间和播放区间
- 开关轨迹、矢量、测量值、公式和高亮
- 修改标题、标签、公式说明和结论
- 选择关键时刻，例如开始、最高点、碰撞和结束
- 恢复模板默认讲解步骤

P0 不支持任意轨道、复杂转场、字幕编辑、配音和背景音乐。

### 4.7 画面与导出

- P0 只支持 `9:16` 竖屏，先把一种构图做完整。
- 默认构图面向 TikTok、YouTube Shorts 和 Instagram Reels，安全区不得依赖单个平台的界面覆盖位置。
- 编辑器实时显示安全区和越界提示。
- P0 在本机按固定帧导出 720p H.264 MP4，不录制用户浏览器画面。
- 导出前运行科学检查和构图检查。
- 显示渲染进度、完成和失败状态，并允许从相同项目版本重试。
- `16:9`、`1:1`、1080p、云端队列、额度和私有预览链接进入付费 Beta。

### 4.8 付费 Beta 的账户与订阅

以下功能只有在 P0 用户验证达到进入条件后才实施：

- 邮箱魔法链接或 Google 登录。
- 首次体验不要求付款信息。
- Creem Checkout 完成订阅，Webhook 是权益状态的唯一可信来源。
- 账单页显示方案、续费日期、渲染额度和管理订阅入口。
- 取消后权益保留至当前周期结束。
- 计费采用“功能权限 + 每月渲染分钟”，不限制项目数量。

建议试运营方案：

| 方案 | 权益 |
|---|---|
| Free | 3 次带水印 720p 导出 |
| Creator | 无水印、1080p、固定月度渲染分钟 |

正式价格必须在渲染成本实测和 5-8 位目标用户访谈后确定。

### 4.9 AI 边界

AI 不进入首个技术闭环。完成稳定模拟与导出后，才增加：

- 将用户描述匹配到模板和参数建议
- 根据讲解步骤生成标题、讲解提纲和字幕初稿
- 用通俗语言解释确定性检查结果

所有 AI 建议必须由用户确认后才能修改项目。

## 5. 核心流程

### 从斜面模板导出竖屏视频

1. 打开“斜面受力与摩擦”默认竖屏项目。
2. 输入角度、质量和摩擦系数。
3. 开启重力、支持力、摩擦力和加速度显示。
4. 预览运动，并查看滑动条件和理论加速度。
5. 调整五个默认讲解步骤的文字和持续时间。
6. 处理科学检查和画面越界问题。
7. 在本机导出 720p MP4。

## 6. P0 验收条件

- 新用户可以在 10 分钟内导出第一段 20-30 秒视频。
- 相同项目版本重复导出的关键帧和测量值一致。
- 修改参数后，场景、公式、图表、讲解和检查同步更新。
- 斜面模板的解析值、边界条件和关键事件基准通过自动测试。
- 科学检查能定位到具体参数或讲解步骤。
- 刷新浏览器后，项目恢复到最近的本地版本。
- 5-8 位英语市场目标用户完成测试，多数人能独立完成首次导出。
- 至少 3 位用户提出真实复用场景，并出现明确的高清无水印付费意愿。

## 7. 首版之后

只有出现以下信号，才开放通用编辑能力：

- 至少 20 位用户在 30 天内完成两次以上导出。
- 用户反复提出同类“模板缺少一个物体或约束”需求。
- 至少一个模板形成稳定复用场景。

后续顺序：更多模板 -> 自定义模板参数 -> 模板复制与分享 -> 有限的场景编辑 -> 教师课堂模式。三维、流体和专业工程仿真不进入近期路线图。

## 8. 产品指标

北极星指标：每周成功导出的有效科学项目数。

P0 尚未上线订阅，先记录首次导出耗时、完成率、需要协助的步骤、第二次使用意愿和付费意愿。进入付费 Beta 后再启用下面的产品漏斗。

关键漏斗：

- 查看模板 -> 创建项目
- 创建项目 -> 首次播放
- 首次播放 -> 修改讲解步骤
- 修改步骤 -> 提交导出
- 免费额度触发 -> 完成订阅
- 首次导出 -> 7 天内第二次导出

“有效项目”必须包含至少一次参数修改、一个科学可视化和一次成功导出。

## 9. 待验证假设

1. 创作者愿意为可编辑、可信和稳定导出付费。
2. 斜面模板足以暴露编辑与导出工作流问题，但模板需求必须在后续继续验证。
3. 结构化讲解步骤能覆盖首批短视频，不需要完整时间线。
4. 10 分钟产出第一段内容具有明显价值。
5. 模板和导出稳定性比自由搭建能力更重要。
