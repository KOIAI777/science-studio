# Science Studio

面向科学老师和科普创作者的可视化实验内容工作台。

用户无需编程即可搭建二维物理实验、调整参数、验证科学关系，并将实验过程导出为视频、GIF 或可交互网页。

## 当前产品共识

- 首发用户：需要持续制作课程和短视频的科学老师、科普创作者。
- 首发领域：二维经典力学，不做通用三维仿真平台。
- 核心工作流：选择模板 -> 调整实验 -> 检查结果 -> 编排讲解 -> 导出发布。
- 核心差异：不是“提示词生成动画”，而是可编辑、可验证、可复用的科学内容生产工具。
- 产品形态：桌面优先的 Web SaaS，中文优先，后续支持英文。
- 商业模式：订阅制，通过 Creem 收款；具体价格在完成用户访谈和成本测试后确定。
